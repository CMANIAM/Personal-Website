Scoutermation

What it is: Scoutermation is a troop management platform designed to make it easier for scouting leaders to communicate, organize tasks, and share important information. It includes features such as chat, visual boards, and file storage, helping troops keep track of meetings, events, and resources in one place.

My role: I helped develop the data side of the application using Bubble. I created and modified data types and worked with API calls to manage information throughout the app. I also helped make the application dynamic and personalized so different users and troops could access their own relevant information.
